## Linux commands I learned
| Command | What it does | Example |
|---|---|---|
| `echo` | Repeats back whatever I type | `echo hello` |
| `pwd` | Shows the directory I'm currently working in (print working directory) | `pwd` |
| `cd` | Changes my working directory | `cd notes` |
| `ls` | Lists files and folders in a directory | `ls` |

- `ls` has options that change the output, e.g. `ls -l` (detailed list) and `ls -a` (show hidden files).
- Also covered: Linux history and what the shell is (the program that reads my commands and runs them).

## Biology: Central Dogma
DNA -> RNA -> Protein

- **Transcription:** The cell makes a temporary, single-stranded copy of a gene's DNA called **mRNA**, inside the nucleus.
- **Translation:** The mRNA leaves the nucleus and goes to a **ribosome**. The ribosome reads the genetic code in sets of 3 letters called **codons**, and links amino acids together to make a functional protein.
